# Cognition Engine

This project is the backend system for analyzing CRM deal data from HubSpot and producing intelligent, context-aware, and proactive ICP segmentation insights, as outlined in the technical requisition document (`instruction.txt`).

## Objective
Build a cognition-first, LLM-powered backend system that analyzes CRM deal data from HubSpot and produces intelligent, context-aware, and proactive ICP segmentation insights. This system will not serve as a traditional dashboard, but as an AI-driven GTM Brain capable of perception, memory, reasoning, and execution.
